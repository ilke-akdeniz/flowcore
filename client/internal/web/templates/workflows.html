Three fields rather than one, because FlowCore refuses a definition with no steps — a workflow that cannot be started is not a state it will store. So there is no "create it empty and fill it in later".

The assignee is a free text field on purpose. Nothing validates it, nothing completes it, and FlowCore never interprets it. Type anything:at-all and the workflow still runs — that is what "opaque reference" means. Values starting with agent: are dispatched automatically, which is this application's convention, not the library's.
