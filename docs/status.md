# Project Status

Permanent project state.
The states that move an iteration or slice or a pending-task in the docs/pending-tasks folder between them:

*Not started* — no source code or no "major output" about the task exists yet. "Major output" means what the task is trying to produce. Ex: For "iteration 1", a record of ideas about iteration 1 is not "major output". A design document is major output.
*In progress* — We are working on major outputs.
*Complete* — Major outputs are complete, claude can propose that "In progress" can move to "Complete" but human decides on that.
